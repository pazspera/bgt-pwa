  ❓ ¿Cómo conviene interactuar con la API?
  ✅ COMPOSABLES + FETCH (patrón actual del proyecto)
     Vista → Composable → API Service → Fetch → API

  ❓ ¿Con Fetch o con Pinia?
  ✅ AMBOS tienen su lugar:
     - Composables: Para operaciones específicas de API ✅ Recomendado
     - Pinia: Para estado global compartido, caché
     - Fetch directo: ❌ Nunca (poca reutilización)

┌────────────────────────────────────────────────────────────────────┐
│  📖 EJEMPLO DE USO RÁPIDO                                          │
└────────────────────────────────────────────────────────────────────┘

  <script setup>
  import { onMounted } from 'vue';
  import { usePlayersApi } from '@/composables/usePlayersApi';

  const { 
    players, 
    loading, 
    error, 
    fetchPlayers, 
    createPlayer 
  } = usePlayersApi();

  // GET - Listar jugadores
  onMounted(() => fetchPlayers());

  // POST - Crear jugador
  const handleCreate = async () => {
    const newPlayer = await createPlayer('Zeuchi5');
    if (newPlayer) {
      console.log('Creado:', newPlayer);
    }
  };
  </script>

  <template>
    <div>
      <button @click="handleCreate">Crear</button>
      
      <p v-if="loading">Cargando...</p>
      <p v-if="error">{{ error }}</p>
      
      <ul v-else>
        <li v-for="p in players" :key="p.id">
          {{ p.name }}
        </li>
      </ul>
    </div>
  </template>
